# بوابة بلدية ظفار الرقمية الموحدة (Dhofar Digital Matrix)

هذا المشروع هو النظام الأساسي المطور لبوابة بلدية ظفار الإلكترونية، مصمم لتقديم تجربة مستخدم استثنائية وشاملة تتماشى مع رؤية عُمان 2040 ومعايير النفاذ الرقمي العالمية WCAG 2.2.

## 🚀 التقنيات المستخدمة (Technical Stack)

- **Framework**: Next.js 15.1 (App Router) - لأداء فائق وتجربة تطوير حديثة تعتمد على المكونات الخادمة (Server Components).
- **Primary Color**: **Vital Teal (#03CFCB)** - يمثل الحداثة والوضوح.
- **Secondary Color**: **Royal Purple (#470D67)** - يمثل الهيبة والصبغة الحكومية الرسمية.
- **Typography**: **Readex Pro** - الخط الرسمي المعتمد للبوابة (Arabic/English) لسهولة القراءة.
- **UI Architecture**: Shadcn UI & Radix UI - مكتبة مكونات متوافقة مع معايير الوصول (Accessibility).
- **Data Engine**: Firebase Firestore & Auth - لإدارة البيانات المباشرة والمصادقة الوطنية.
- **AI Brain**: Google Genkit - لمعالجة الترجمة العصبية والمساعد الذكي.
- **Visualization**: Recharts - لعرض البيانات والإحصائيات الحيوية والمالية بدقة عالية.

## 🎨 الهوية البصرية (Visual Identity)

تعتمد البوابة هوية بصرية ملكية رصينة:
- **التركواز الحيوي (#03CFCB)**: اللون الأساسي للتفاعل والأزرار.
- **الأرجواني الملكي (#470D67)**: لون العلامة التجارية والترويسات الرسمية.
- **الأنماط (Patterns)**: 
  - `.dm-wave`: نمط الأمواج الرسمي.
  - `.dm-pattern-polygon`: النمط الهندسي للمصفوفة الرقمية.

## 📂 هيكلة المجلدات (Project Structure)

- `src/app`: المجلد الرئيسي للصفحات والراوتات.
- `src/app/identity`: الموسوعة الهندسية الشاملة (300+ مكون).
- `src/app/admin`: لوحة التحكم المركزية بالخدمات والمحتوى.
- `src/components`: المكونات القابلة لإعادة الاستخدام.
- `src/ai`: تدفقات الذكاء الاصطناعي الخاصة بـ Genkit.
- `src/lib`: المخازن الحالة (Zustand) والتعاريف والخدمات.

## 🛠 الشاشات الرئيسية (Core Screens)

1. **دليل الهوية (Identity Hub)**: مرجع تقني يضم كافة أنواع البطاقات، الجداول، الرسوم البيانية، والنماذج الجاهزة للاستخدام بنظام Masonry.
2. **الصفحة الرئيسية (Neural Home)**: محرك بحث ذكي، بوابة "ثقة" للمصادقة الوطنية، واستطلاعات رأي تفاعلية نشطة.
3. **دليل الخدمات (Catalog)**: تصنيف ذكي لكافة الخدمات البلدية.
4. **محرك تدفق العمل (Workflow Engine)**: نظام مرئي لبناء مراحل الخدمات البلدية.
