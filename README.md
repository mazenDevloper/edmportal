# بوابة بلدية ظفار الرقمية الموحدة (Dhofar Digital Matrix)

هذا المشروع هو النظام الأساسي المطور لبوابة بلدية ظفار الإلكترونية، مصمم لتقديم تجربة مستخدم استثنائية وشاملة تتماشى مع رؤية عُمان 2040 ومعايير النفاذ الرقمي العالمية WCAG 2.2.

## 🚀 التقنيات المستخدمة (Technical Stack)

- **Framework**: Next.js 15 (App Router) - لأداء فائق وتجربة تطوير حديثة تعتمد على المكونات الخادمة (Server Components).
- **Styling**: Tailwind CSS - نظام تصميم مرن يعتمد على الفئات مع دعم كامل للهوية البصرية الملكية.
- **UI Components**: Shadcn UI & Radix UI - مكتبة مكونات متوافقة مع معايير الوصول (Accessibility).
- **Generative AI**: Google Genkit - لمعالجة الترجمة العصبية والمساعد الذكي.
- **Animations**: Framer Motion & Parallax Tilt - لحركات واجهة مستخدم سلسة واحترافية.
- **Charts**: Recharts - لعرض البيانات والإحصائيات الحيوية والمالية بدقة عالية.
- **Typography**: Readex Pro - الخط الرسمي المعتمد للبوابة (Arabic/English).

## 🎨 الهوية البصرية (Visual Identity)

تعتمد البوابة هوية بصرية ملكية رصينة:
- **الأرجواني الملكي (#470D67)**: اللون الأساسي للعلامة التجارية.
- **التركواز الحيوي (#03CFCB)**: لون التأكيد والتفاعل (Accent).
- **الأنماط (Patterns)**: 
  - `.dm-wave`: نمط الأمواج الرسمي.
  - `.dm-pattern-polygon`: النمط الهندسي للمضلعات.

## 📂 هيكلة المجلدات (Project Structure)

- `src/app`: المجلد الرئيسي للصفحات والراوتات.
- `src/app/identity`: المرجع الهندسي الشامل (300+ مكون).
- `src/app/admin`: لوحة التحكم المركزية بالخدمات والمحتوى.
- `src/components`: المكونات القابلة لإعادة الاستخدام (الترويسة، التذييل، البطاقات).
- `src/ai`: تدفقات الذكاء الاصطناعي الخاصة بـ Genkit.
- `src/lib`: المخازن الحالة (Zustand) والتعاريف والخدمات.

## 🛠 الشاشات الرئيسية (Core Screens)

1. **دليل الهوية (Identity Hub)**: موسوعة تقنية تضم كافة أنواع البطاقات، الجداول، الرسوم البيانية، والنماذج الجاهزة للاستخدام.
2. **الصفحة الرئيسية (Neural Home)**: محرك بحث ذكي، بوابة "ثقة" للمصادقة الوطنية، واستطلاعات رأي تفاعلية.
3. **دليل الخدمات (Catalog)**: تصنيف ذكي لكافة الخدمات البلدية (أكثر من 80 خدمة).
4. ** Workflow Engine**: نظام مرئي لبناء مراحل الخدمات البلدية بربط منطقي.
