# بوابة بلدية ظفار الرقمية الموحدة (Dhofar Digital Matrix)

هذا المشروع هو النظام الأساسي المطور لبوابة بلدية ظفار الإلكترونية، مصمم لتقديم تجربة مستخدم استثنائية وشاملة تتماشى مع رؤية عُمان 2040 ومعايير النفاذ الرقمي العالمية WCAG 2.2.

## 🚀 التقنيات المستخدمة (Technical Stack)

- **Framework**: Next.js 15.1 (App Router) - لأداء فائق وتجربة تطوير حديثة.
- **Primary Color**: **Vital Teal (#03CFCB)** - يمثل الحداثة والوضوح الرقمي.
- **Secondary Color**: **Royal Purple (#470D67)** - يمثل الهيبة والصبغة الحكومية الرسمية.
- **Typography**: **Readex Pro** - الخط الرسمي المعتمد للبوابة لسهولة القراءة والاتساق البصري.
- **UI Architecture**: Shadcn UI & Radix UI - مكتبة مكونات متوافقة مع معايير الوصول.
- **Data Engine**: Firebase Firestore & Auth - لإدارة البيانات المباشرة والمصادقة الوطنية "ثقة".
- **AI Brain**: Google Genkit - لمعالجة الترجمة العصبية والمساعد الذكي المكاني.
- **Visualization**: Recharts - لعرض البيانات والإحصائيات الحيوية بدقة عالية.

## 🎨 الهوية البصرية (Visual Identity)

تعتمد البوابة هوية ملكية معاصرة:
- **التيل الحيوي (#03CFCB)**: اللون الأساسي للتفاعل والأزرار.
- **الأرجواني الملكي (#470D67)**: لون العلامة التجارية والترويسات الرسمية.
- **الأنماط الرسمية (Patterns)**: 
  - `.dm-pattern-landmark`: نمط المعالم الحضارية.
  - `.dm-pattern-wave-pro`: نمط الأمواج الانسيابية.
  - `.dm-pattern-tree-pro`: نمط الشجرة العمانية.
  - `.dm-pattern-circle-pro`: نمط الدوائر المتداخلة.
  - `.dm-pattern-matrix-all`: النمط الشامل المدمج.

## 📂 هيكلة المجلدات (Project Structure)

- `src/app`: المجلد الرئيسي للصفحات والراوتات الديناميكية.
- `src/app/identity`: الموسوعة الهندسية الشاملة (300+ مكون) بنظام Masonry.
- `src/app/admin`: لوحة التحكم المركزية بالخدمات والمحتوى والاستطلاعات.
- `src/components`: المكونات الذرية والقابلة لإعادة الاستخدام.
- `src/ai`: تدفقات الذكاء الاصطناعي (Genkit Flows).
- `src/lib`: المخازن الحالة (Zustand) والتعاريف والخدمات المشتركة.

## 🛠 الشاشات الرئيسية (Core Screens)

1. **دليل الهوية (Identity Hub)**: مرجع تقني يضم كافة أنواع البطاقات، الجداول، الرسوم البيانية، والنماذج الجاهزة.
2. **الصفحة الرئيسية (Neural Home)**: محرك بحث ذكي، بوابة "ثقة" للمصادقة الوطنية، واستطلاعات رأي تفاعلية.
3. **دليل الخدمات (Catalog)**: تصنيف ذكي لكافة الخدمات البلدية (بناء، صحة، استثمار، إلخ).
4. **محرك تدفق العمل (Workflow Engine)**: نظام مرئي لبناء مراحل الخدمات البلدية بشكل منطقي.
